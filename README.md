# tdrive-aliyunpan

把阿里云盘的文件同步到 [tdrive](https://github.com/dibin666/tdrive)（备份至 Telegram）。

插件按账号独立安装，归安装账号所有。

## 安装

在 tdrive「设置」→「插件」→「安装插件」中输入以下地址：

```
https://github.com/dibin666/tdrive-aliyunpan/releases/latest/download/tdrive.plugin.json
```

- 地址指向最新版本。在插件列表点击「检查更新」即可升级。
- 支持 Linux、Windows（amd64 / arm64）。内置客户端，无需安装额外工具。

## 使用方法

安装后在「设置」→「插件」→「阿里云盘同步」打开控制台。插件归当前账号所有，上传文件默认记入该账号。

- **账号**：扫码登录阿里云盘。登录信息持久化保存，重启插件无需重新扫码。
- **任务**：创建同步任务。支持备份盘与资源库；支持整目录镜像，也支持直接勾选文件与目录。
- **同步**：查看传输队列，支持批量重试、取消与清理历史。
- **下载文件**：查看本地暂存占用与下载进度，支持手动删除或清理无主文件。
- **计划与限额**：配置允许同步的时间段、扫描间隔与每日上传流量上限。

## 功能特性

- **按需同步**：支持目录镜像与手动挑选；支持文件大小与正则表达式过滤；可选上传后删除云端原文件。
- **避免重复**：记录已完成文件，避免重复下载与占用配额；修改目标目录不会重传。
- **断点续传**：支持分片断点续传与下载链接自动刷新；网络中断或插件重启无需重新下载。
- **失败重试**：传输异常自动退避重试；保留已下载分片；支持批量手动重试。
- **配额与并发**：支持限制每日上传流量、运行时间段与阿里云盘下载并发数。
- **暂存保护**：文件成功写入 tdrive 后才删除本地暂存，避免失败重试时重复下载。
