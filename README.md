# tdrive-aliyunpan

把阿里云盘的文件自动同步到 [tdrive](https://github.com/dibin666/tdrive)（即备份至 Telegram）的插件。

## 安装

在 tdrive 的「设置」→「插件」→「安装插件」中，粘贴以下地址：

```
https://github.com/dibin666/tdrive-aliyunpan/releases/latest/download/tdrive.plugin.json
```

- 该地址始终指向最新版本，后续在插件列表点击「检查更新」即可一键升级。
- 支持 Linux、Windows（amd64 / arm64），内置网盘客户端，无需额外安装任何命令行工具。

## 使用方法

安装后，在 tdrive 进入「设置」→「插件」→「阿里云盘同步」点击打开即可使用。

- **账号**：直接扫码登录，登录信息持久化保存，插件重启或更新无需重新扫码。
- **任务**：创建同步任务，支持备份盘与资源库；可按目录映射，也可在界面中直接勾选文件与文件夹。
- **同步**：查看实时传输队列，支持批量重试、批量取消与清理记录。
- **下载文件**：查看本地暂存文件的磁盘占用与下载进度，支持手动清理或一键清除无主文件。
- **计划与限额**：设置每天允许同步的时间段、扫描间隔与每日上传流量上限。

## 功能特性

- **灵活同步**：支持目录映射与手动挑选文件，支持按文件大小、正则表达式过滤，可选上传后删除云端原文件。
- **防重复传输**：自动记录已完成的文件，避免重复下载与占用每日配额；调整目标目录也不会触发重传。
- **断点续传**：支持精确断点续传与下载链接提前刷新，遇到网络中断或插件重启无需重新下载。
- **自动重试**：传输异常自动重试，失败任务支持一键手动批量重试。
- **流量与并发控制**：支持设置每日上传流量上限、运行时间窗口以及阿里云盘下载并发数。
- **安全缓存管理**：默认仅在文件成功上传到 tdrive 后才删除本地缓存，避免失败重试时重复下载。
